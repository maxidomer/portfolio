PHP-сессии

Установка

Распакуйте файлы в папку сайта.

Убедитесь, что index.html, api.php и favicon.svg находятся в корне.

Папка data должна находиться рядом с ними.

Откройте сайт.

Нажмите кнопку terminal или Ctrl + Shift + D.

Войдите в панель разработчика.

Данные входа

Демонстрационная конфигурация:

Логин: maxim
Пароль: MaximDev!2026#Secure

После установки обязательно измените пароль, если сайт будет доступен другим людям.

Не публикуйте настоящий пароль в GitHub.

Панель разработчика

Авторизованный разработчик может:

добавлять проекты;

задавать название;

выбирать категорию;

выбирать иконку;

добавлять описание;

добавлять тег;

удалять проекты.

Проекты сохраняются на сервере и становятся видны посетителям сайта.

Защита

Добавление и удаление проектов выполняется через api.php.

Сервер повторно проверяет запросы и текст проектов. Поэтому простой вызов JavaScript через DevTools не должен позволять обойти серверную проверку.

Фильтр нежелательного текста не является заменой полноценной модерации для публичного сервиса с большим количеством пользователей.

Шрифты и иконки

Используются:

Inter — основной шрифт;

Manrope — заголовки;

Material Symbols Rounded — иконки.

По умолчанию они подключаются через Google Fonts.

Настройка

Основной интерфейс и данные находятся в index.html.

Серверная логика находится в:

api.php

Хранилище проектов:

data/projects.php

Безопасность перед публикацией

Перед размещением сайта:

Измените пароль администратора.

Проверьте права доступа к data.

Убедитесь, что PHP выполняется сервером.

Включите HTTPS.

Не публикуйте резервные копии с паролями.

Не храните токены и секреты в GitHub.

Регулярно обновляйте PHP и сервер.
