# MAXIM Portfolio

> Персональное портфолио с интерактивным интерфейсом, анимациями и собственной панелью разработчика.

## Preview

**MAXIM Portfolio** — современный персональный сайт, посвящённый моим проектам, экспериментам и разработкам.

### Возможности

* Современный responsive-дизайн
* Динамический анимированный фон
* 3D-эффекты и интерактивные карточки
* Плавные UI-анимации
* Светлая и тёмная тема
* Material Symbols вместо эмодзи
* Собственная favicon
* Панель разработчика
* Авторизация администратора
* Добавление и удаление проектов
* Серверное хранение проектов
* Серверная проверка содержимого

## Проекты

### Мотор на велосипеде

Экспериментальный проект, связанный с установкой двигателя на велосипед.

### Тренировка кастомного ИИ
